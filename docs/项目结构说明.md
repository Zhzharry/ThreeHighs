# 项目结构说明

这个项目按前后端分离组织：

```text
大作业/
├── frontend/                 # 前端
│   ├── miniprogram/          # 微信小程序源码
│   │   ├── pages/            # 页面代码
│   │   ├── services/         # 前端 API 请求封装
│   │   └── assets/           # 小程序静态资源
│   └── preview/              # 历史浏览器预览源码，默认不启动
├── backend/                  # 后端
│   ├── app/
│   │   ├── api/              # Flask-RESTful API
│   │   ├── models/           # SQLAlchemy 数据模型
│   │   └── services/         # OCR、预测、大模型、向量库服务
│   ├── tests/                # 后端测试
│   └── requirements.txt
├── docs/                     # 文档
│   ├── api.md                # API 接口文档
│   ├── 需求分析.md
│   └── 项目结构说明.md
├── docker-compose.yml        # 同时启动前端预览和后端 API
├── project.config.json       # 微信开发者工具配置
└── README.md
```

## 老师查看时可以这样讲

- 前端代码在 `frontend/miniprogram`。
- 后端代码在 `backend`。
- 接口文档在 `docs/api.md`。
- 需求分析在 `docs/需求分析.md`。
- 前端资源在 `frontend/miniprogram/assets`。
- Docker 启动配置在 `docker-compose.yml`。

## 前后端通信边界

- 前端页面通过 `wx.request` 请求后端接口。
- 后端通过 Flask-RESTful 提供 JSON API。
- OCR、预测、大模型和向量库不写在前端，统一放在后端 `services` 中封装。
