# 交付包使用说明

## 结论

压缩包可以复制到另一台 Windows 电脑并启动，但不是“双击压缩包即可运行”。接收方必须先安装并启动 Docker Desktop；查看微信小程序还需要安装微信开发者工具。第一次启动需要联网下载基础镜像。

## 交付包包含

- 微信小程序完整源码与 ECharts 组件。
- Flask 后端、数据库模型、Alembic 迁移和自动化测试。
- 历史浏览器预览源码（仅用于追溯，不默认启动、不作为验收入口）。
- Docker Compose、MySQL、Redis、上传持久卷配置。
- 开发环境启动/停止脚本。
- 需求、数据库、API、迭代记录和上线部署文档。
- `docs/项目交接文档.md`，用于接手开发、人员分工和上线准备。

## 交付包不包含

- 本机 Python `.venv`，Docker 会在镜像内安装依赖。
- `.pytest_cache`、`__pycache__`、Playwright 临时数据。
- `project.private.config.json`，它属于本机微信开发者工具配置。
- `.env`、AppSecret、正式密钥或其他凭证。
- 本机 SQLite 数据库、历史备份和 Docker MySQL/Redis 数据卷。
- 微信开发者工具、Docker Desktop及其镜像缓存。

因此，新电脑启动后会创建一套新的数据库并初始化演示数据，不会自动复制打包电脑上的用户记录。如果需要迁移真实数据，应另行进行 MySQL 备份、加密传输和恢复，不能把数据库文件随源码公开分发。

## 新电脑最低要求

- Windows 10/11 64 位。
- Docker Desktop，且 WSL 2/虚拟化可用。
- 首次构建时可以访问容器镜像与 Python 包网络源。
- 建议至少 8 GB 内存和 10 GB 可用磁盘空间。
- 查看小程序时安装微信开发者工具并登录微信账号。

普通运行不要求接收方单独安装 Python、MySQL、Redis或 Node.js，因为后端依赖由 Docker 镜像提供。若要运行微信开发者工具自动化冒烟测试，需要另外安装 Node.js 并执行 `npm install`。

## 启动方式

1. 使用最新版 Bandizip 或 7-Zip 解压到普通目录，路径可以包含中文，但不建议放在系统保护目录。交付包由 Bandizip 生成并包含标准 Unicode Path 扩展字段；旧版或不支持 Unicode ZIP 扩展的解压软件可能显示中文乱码。
2. 启动 Docker Desktop，等待状态显示 Engine running。
3. 在解压目录右键打开 PowerShell。
4. 运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\启动开发环境.ps1
```

5. 脚本会检查 Docker、构建后端镜像、执行数据库迁移、启动 MySQL/Redis/后端并等待健康检查；不会打开网页。

启动后后端健康检查地址为 `http://127.0.0.1:5000/api/v1/health`。所有前端界面必须在微信开发者工具中查看和验收。

## 微信开发者工具打开

1. 打开微信开发者工具并选择“导入项目”。
2. 目录选择解压后的项目根目录，不要只选择 `frontend/miniprogram`。
3. 工具会根据 `project.config.json` 使用 `frontend/miniprogram/` 作为小程序根目录。
4. 如果接收方不是当前 AppID 的项目成员，不能以原 AppID 完成正式调试、体验版上传或发布。此时可以选择测试号，或将项目 AppID 改为接收方有权限的 AppID。
5. 确认 Docker 后端已经启动，再点击“编译”。开发版接口默认访问 `http://127.0.0.1:5000/api/v1`。

启动开发者工具自动化端口后，可在项目根目录执行 `npm run test:miniprogram`；该测试只操作开发者工具中的小程序实例。

## 停止方式

```powershell
powershell -ExecutionPolicy Bypass -File .\停止开发环境.ps1
```

该命令只停止容器，保留数据库、Redis和上传文件。不要随意执行 `docker compose down -v`，因为 `-v` 会删除本机运行数据。

## 常见问题

### 端口冲突

项目默认使用 `5000` 和 `3307`。如果这些端口已被其他程序占用，需要先停止占用程序，或修改 `docker-compose.yml` 的宿主机端口；修改5000端口后还要同步小程序开发环境 API 地址。

### 镜像下载失败

启动脚本默认使用 `public.ecr.aws/docker/library`。如果所在网络无法访问，可以临时指定其他兼容镜像仓库：

```powershell
$env:DOCKER_BASE_REGISTRY = "docker.io/library"
.\启动开发环境.ps1
```

### 小程序接口请求失败

- 确认健康检查地址能返回 `status=ready`。
- 确认微信开发者工具当前使用 develop 环境。
- 清理小程序缓存并重新编译，避免保留旧 Token。
- 真机调试不能使用电脑的 `127.0.0.1`；需要局域网可访问地址或 HTTPS 测试域名。

### 正式上线

交付包默认启动的是 development 环境。正式部署不能直接使用演示密码或 HTTP 地址，必须按 `docs/上线部署清单.md` 配置生产密钥、数据库账号、HTTPS、微信合法域名和正式登录。
